## 一句话背景

实习生，**无五险一金、不交个税 → 应发＝实发**；日薪 150，计薪周期上月 21 日—本月 20 日，发薪 25 日（**逢休息日/节假日提前发**）；父母每月给 2,000 元生活费；公司免费人才公寓（水电自理、按季结算）。

## 目标与结论

> **2027-02-05 出发回家当天，储蓄账户 ≥ 10,000 元。**
> 精算结果：**③小荷包 11,991.74 元**，扣除代管的 1—2 月水电 231.06 后，**净存款 11,760.68 元**。

```
日常预算      7,450.65（135 天 × 日额度 55.19）
专项支出        449.28（Q4水电 405.88 ＋ 理发补差 43.40）
```

## 三个账户（只新开一个）

```
① 工资卡（已有）   每天从这里花钱；早上由②划入 55.19，晚上结余退回②；过夜 ≤100 元
② 余额宝           本期预算池 ＝ 55.19 × 本期天数；每天分批划给①
③ 支付宝小荷包     全部储蓄（含水电等专项预留）；只进不出；仅水电/理发从中划出
```

★ **整套机制的生效前提（App 外必须手动做）**：支付宝 → 支付设置 → 扣款顺序设为**仅银行卡①**，余额宝与小荷包**不参与递补**。否则每天划 55.19 形同虚设。

## 两个最容易做错的地方（交给任何人时务必强调）

1. **还花呗/月付/白条 ＝ 划转，不是支出。** 消费当天已计入日额度，还款只是把钱搬到平台。若把还款记成支出，同一笔钱算两次，日额度与储蓄全错。
2. **最后一期区间是 1/25 → 2/5（12 天），不是到下个发薪日。** 因为目标截止日是出发回家那天，且不把 2/25 的工资算进来。忘了这个特例，五期数据全错。
