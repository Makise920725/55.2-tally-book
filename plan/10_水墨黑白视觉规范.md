# 水墨黑白 · 视觉设计规范（v8 起生效）

> 你说要「黑白、水墨、极简」。这份规范把原来那套**墨绿 + 暖黄**的深色主题整体替换掉。
> 适用范围：小程序 UI、原型、头像、启动页、分享卡。
> **铁律：任何页面里不许自己写色值，只能从下面的令牌里取。**

---

## 〇、一句话原则

> **纸是底，墨是信息，留白是层级，朱砂一屏只出现一次。**

- 一屏 99% 是纸与墨；朱砂（印泥红）全屏只允许 **1 处、直径 ≤ 8px**。
- 层级不靠颜色区分，靠 **字号 + 灰阶 + 留白**。
- 装饰性东西一律不要：插画、彩色图标、渐变、阴影、玻璃拟态、emoji。

---

## 一、色板（水墨令牌）

### 1.1 纸（背景层）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#F4F1EA` | 全局底色（宣纸） |
| `--paper-2` | `#EDE8DE` | 分区底、按压态 |
| `--card` | `#FBF9F4` | 卡片（比纸更白一档，像皮纸） |

### 1.2 墨（内容层 · 五级灰阶＝整套设计的骨架）

| 令牌 | 值 | 名 | 用途 |
|---|---|---|---|
| `--ink-1` | `#141412` | 焦墨 | 主数字、标题、主按钮底 |
| `--ink-2` | `#2E2C28` | 浓墨 | 正文、次级数字 |
| `--ink-3` | `#6E6B64` | 重墨 | 标签、说明 |
| `--ink-4` | `#A8A29A` | 淡墨 | 占位、禁用、次要说明、**超支** |
| `--ink-5` | `#C9C2B4` | 清墨 | 分隔线、网格、轨道 |

> **只有 5 级灰，不许出现第 6 级。** 一个元素该用哪级，只由它在信息层级里的位置决定。

### 1.3 朱砂（印）

| 令牌 | 值 | 唯一用途 |
|---|---|---|
| `--seal` | `#9E2E26` | 印章、「已达 10,000」的落印、目标线上的那道刻度 |

- **严禁**用朱砂表示错误 / 超支 / 危险。超支只是「今天用完了」→ 用 `--ink-4` 淡墨（字变虚），不许红。
- 一屏最多 1 处，只能出现在右下角或标题旁，尺寸 ≤ 8px。

### 1.4 夜墨（深色模式，可选）

| 令牌 | 值 |
|---|---|
| bg | `#121210` |
| card | `#1A1A17` |
| line | `#2C2B26` |
| 文字四级 | `#F2EFE6` / `#D9D4C7` / `#95908A` / `#6A655D` |
| seal | `#9E2E26`（不变） |

原型右下角那颗「墨 / 纸」圆点就是两版开关。**建议两版都做完再决定上不上夜墨**——22:00 结算场景确实需要暗色。

## 二、字体

| 用途 | 字族 | 说明 |
|---|---|---|
| **数字（金额／百分比）** | 衬线：`Noto Serif SC`、`Songti SC` | 宋体的笔锋＝水墨最重要的落差点 |
| 中文标题 | 同上，weight 500 | 只允许 400 / 500 两档 |
| 正文·说明 | `PingFang SC`、`Microsoft YaHei` | 小字号无衬线更清晰，别硬撑宋体 |
| 金额对齐 | `font-variant-numeric:tabular-nums` | 必须等宽，能一眼比对 |

字号阶梯（px，**只允许这 8 档**）：**44 / 34 / 19 / 16 / 13.5 / 12.5 / 11 / 10**
主数字（今天还能花）永远 44px，其它一律让路。

字距：≤11px 的小字配 `letter-spacing:2~4px`（题跋感）；数字反之 `-1px`。

---

## 三、形（极简三条硬规矩）

1. **圆角 ≤ 2px。** 圆形只允许出现在三处：头像、圆相环、模式开关。
2. **没有阴影。** 层次全靠 1px `--ink-5` 描边 + 留白。
3. **卡片间距 ≥ 12px、内边距 16px。** 留白是主分隔，线只是补充。

栅格：设计稿宽 **750rpx**，左右安全边距 **28rpx**，卡片纵向间距 **24rpx**。

## 四、组件（水墨版）

### 4.1 圆相环（替代原圆环进度）
一笔画不满的禅圈：`stroke-width 8`、`linecap round`、起点旋转 128°，**永远留 7% 的缺口**（未圆满）。
- 轨道 `--ink-5` 1.4px；进度 `--ink-1` 8px
- 用尽时进度转 `--ink-4`（墨淡了＝笔干了），文案「已用尽」，**不红、不感叹号**

### 4.2 一笔横（替代百分比进度条）
3px 高直线，`--ink-1` 实心 + `--ink-5` 轨道；目标位打一道 2px `--seal` 竖刻度。
**不要饼图、不要占比环、不要渐变填充。**

### 4.3 日柱（本期每日支出）
- 未用：`--ink-5` 细条
- 正常：`--ink-1` 实心
- 超支：`--ink-2` 底 + 45° `--paper` 斜纹（**飞白／枯笔**），而不是变红
- 条宽 flex:1、间距 3px、区高 62px、直角无圆角

### 4.4 按钮
- 主：`--ink-1` 底 + `--paper` 字，13.5px/500，圆角 1px，无图标
- 次：透明底 + 1px `--ink-5` 描边 + `--ink-2` 字
- 禁用：`--ink-4` 字 + `--ink-5` 描边（不许糊成灰块）

### 4.5 分类格（八格）
**用汉字，不用 emoji、不用彩色图标**：食 猫 用 零 电 衣 娱 杂
- 底 `--paper-2`、1px `--ink-5`、字 `--ink-2` 11.5px、汉字图标 `--ink-1` 衬线 17px
- 按下＝**整格反相**（`--ink-1` 底 + `--paper` 字）＝落墨手感

### 4.6 标签 chip
1px 细描边空心方框，**不做胶囊圆角**。只有「提前发薪」这类提醒允许 `--seal` 描边（它是提醒，不是警告）。

### 4.7 清单勾选
18px 方框（1px `--ink-5`），完成后整块填 `--ink-1` + 纸色对勾，对应文字降到 38% 不透明度。

### 4.8 提示块
左侧 2px `--seal` 竖线 + 无底色 + `--ink-2` 文字。**不要圆角框、不要浅黄警告底。**

### 4.9 Toast
`--ink-1` 底 + `--paper` 字，圆角 1px，居中偏下。**永远不要红色 toast。**

## 五、旧 → 新 对照（照这个改，别漏）

| 旧（墨绿暖黄） | 新（水墨） |
|---|---|
| 深底 `#0f1512` | 宣纸 `#F4F1EA`，夜墨降为可选 |
| 暖黄强调 `#c9a961` | 焦墨 `--ink-1` 自己就是强调 |
| 绿色＝正常 `#6fbf8f` | 取消语义色：正常＝浓墨，重要＝字号大 |
| 橙红＝超支 `#c97b61` | 超支＝淡墨 `--ink-4` / 飞白斜纹，**不红** |
| 圆角 16px | 1~2px |
| emoji 图标 | 单个汉字（衬线体） |
| 靠颜色分主次 | 靠 字号／灰阶／留白 分主次 |

## 六、可直接粘贴

### 6.1 `styles/theme.wxss`

```css
page{
  --paper:#F4F1EA; --paper-2:#EDE8DE; --card:#FBF9F4;
  --ink-1:#141412; --ink-2:#2E2C28; --ink-3:#6E6B64; --ink-4:#A8A29A; --ink-5:#C9C2B4;
  --seal:#9E2E26;
  background:var(--paper); color:var(--ink-1);
}
.num{ font-family:"Noto Serif SC","Songti SC",serif; font-variant-numeric:tabular-nums; }
.hair{ border:1rpx solid var(--ink-5); border-radius:2rpx; }
```

### 6.2 `utils/theme.js`

```js
module.exports = {
  paper:'#F4F1EA', paper2:'#EDE8DE', card:'#FBF9F4',
  ink1:'#141412', ink2:'#2E2C28', ink3:'#6E6B64', ink4:'#A8A29A', ink5:'#C9C2B4',
  seal:'#9E2E26'
};
```

> canvas 画圆相环时**必须用这份 JS 常量**——canvas 读不到 CSS 变量。

## 七、每个页面交付前自查

1. 截图转灰度，**层级还分得清吗？** 分不清就是靠颜色作弊了 → 重做。
2. 数 `#9E2E26` 出现次数 → **>1 次就改。**
3. 有没有第 6 级灰？有没有阴影？有没有 >2px 圆角？有没有 emoji？——**任一为"有"就返工。**
4. 主数字是不是全页唯一最大？
5. 超支态里**有没有红色？** 有就删。
