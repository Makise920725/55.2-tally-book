# 小程序头像（55块2 · 记账存钱）

生成方式：本地用 System.Drawing 逐笔绘制导出 PNG，非 AI 生图，**无版权风险、可无限重绘**。
源脚本：`outputs\_gen_avatar2.ps1`（改配色/改图形重跑即可，三档尺寸自动一起出）

---

## 一、设计语言（与 05_小程序设计.md 一致）

| 元素 | 取值 |
|---|---|
| 主色·墨绿 | `#16302A` → `#0A1512`（线性渐变） |
| 强调·金 | `#D8B768`（浅面 `#E7C97E` / 深面 `#BE9A4C`） |
| 文字·米白 | `#F4F7F2` |
| 字体 | 微软雅黑 Bold（已验证「块」为真实字形，不是豆腐块） |
| 核心符号 | 大号 **55** + 小号 **块2** —— 就是每天 55.19 日额度的锚点 |

## 二、5 个方案

| 编号 | 文件名前缀 | 画面 | 适合场景 |
|---|---|---|---|
| 01 | `01_mo_green_gold_ring` | 墨绿底 + 金色进度环（走完约七成，象征存钱进度）+ 55 / 块2 | **主推**。最耐看，缩到很小仍清晰 |
| 02 | `02_gold_ground` | 金底墨绿字，反差最强 | 列表里最抢眼，浅色环境下好用 |
| 03 | `03_countdown_bars` | 墨绿底 + 5 根递减金条 = 五期工资、逐月递减的欠款 | 概念最贴「数着日子到除夕」 |
| 04 | `04_cat_bowl` | 墨绿底 + 金色猫耳 + 食盆弧线，中间 55 | 有人味、有猫 |
| 05 | `05_wordmark_gold` | 深墨绿底 + 金色 55 + 米白「块二」+ 一根金下划线 | 纯字标，最像品牌 logo |

## 三、交付规格（逐条核对审核要求）

| 审核要求 | 实际 | 结论 |
|---|---|---|
| 格式 png/bmp/jpeg/jpg/gif | 全部 PNG | ✅ |
| 不大于 2M | 最大 97.27 KB | ✅ |
| 建议 144×144 | 每方案均有精确 144×144 | ✅ |
| 头像会被裁成圆形 | 满版实底、**四角 alpha=255**，无透明洞 | ✅ |
| 圆形裁切不能切到字 | 内容都在中心半径约 0.42 倍画幅的安全区内 | ✅ |
| 不得涉政、涉黄 | 纯几何 + 数字 + 猫碗 | ✅ |

## 四、怎么上传

1. 微信公众平台 → 你的小程序 → **设置 → 基础设置 → 小程序信息 → 头像 → 修改**。
2. 选 **`01_mo_green_gold_ring_144.png`**（推荐），或同方案 512 版；两者都合规。
3. 头像审核一般 1～7 天，期间别再改图，改一次重新排队。
4. 1024 版留着备用：启动页、分享卡、公众号菜单、二维码中心 logo 用同一套色才像一个产品。

> 需要换成别的字标（如「55块2」整词）、5:4 分享图、启动页，基于同一套脚本可以再出。
